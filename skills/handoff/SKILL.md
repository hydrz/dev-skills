name: handoff
description: 将当前对话中的背景、决定、证据和后续动作整理成交接文档，供另一个 agent 继续工作。
argument-hint: "下一个会话要用来做什么？"
disable-model-invocation: true
---

写一份交接（handoff）文档，概括当前对话，让一个全新的 agent 能够接着工作。保存到用户操作系统的临时目录，不放进当前工作区。

文档包含：

- **目标**：这项工作最终要达成什么。
- **当前状态**：已经完成什么、进行到哪一步、哪些已经确定、哪些仍未解决。
- **关键决策与理由**：只写产物中没有记录的“为什么”。
- **下一步**：新会话首先应该做的事。
- **建议使用的 skill**：列出下一个 agent 应该使用的 skill。

已经记录在其他产物中的内容（规格、计划、ADR、issue、提交、diff、进度记录），用路径或 URL 引用，不重复抄写。

脱敏：API key、密码、个人身份信息一律替换为 `<已脱敏>`。

用户传入参数时，把它作为下一个会话的重点，据此取舍文档内容。

写完后，告诉用户文件的绝对路径。
