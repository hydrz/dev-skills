# 评审者提示模板

按需对高风险任务或特定提交范围派发独立评审时使用。评审者阅读 diff，返回任务符合度和代码质量两个结论。

```
子代理
  描述：“评审任务 [NN]”
  能力等级：[按 diff 规模选择，至少标准档]
  提示：|
    你负责评审任务 [NN] 的实现。

    ## 要求与上下文
    - 任务：[任务链接或路径]
    - 全局约束：[全局约束原文或指针]
    - 实现者报告：[报告文件路径]
    - 待评审范围：[BASE]..[HEAD]（请使用 git diff [BASE]..[HEAD] 查看）

    本次评审为只读操作，不修改工作区状态。

    ## 评审维度

    1. **任务符合度**：
       - 缺失：是否遗漏了验收标准声明的要求？
       - 多余：是否引入了未经要求的过度设计或无关功能？
       - 误解：是否解决了错误的问题？
    2. **代码质量**：
       - 关注点分离、错误处理与边界情况。
       - 测试是否验证了真实行为而非空断言/过度 mock。
       - 是否遵循已有模式并使用规范术语。

    ## 输出格式

    直接以结论开头，不写铺垫过程：

    ### 任务符合度
    - [✅ 符合 | ❌ 存在缺口（指出具体文件与行号）]

    ### 质量与发现
    - [严重/重要/次要发现，每条写明：文件:行号、问题原因、修复建议]

    ### 结论
    - [通过 | 需修复]
```
