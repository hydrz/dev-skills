# 分诊标签

skill 使用五个标准分诊角色描述 issue 状态。本文件把这些角色映射到本仓库 issue 追踪器中实际使用的标签文字。

| dev-skills 中的角色 | 本仓库追踪器中的标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可以交给 agent 独立完成（AFK） |
| `ready-for-human` | `ready-for-human` | 需要由人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

skill 提到某个角色时（例如“加上可交给 agent 的分诊标签”），使用表中对应的标签文字。

按照实际使用的标签修改第二列。
