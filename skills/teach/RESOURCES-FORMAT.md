# RESOURCES.md 格式

`RESOURCES.md` 记录这个主题经过筛选的可信来源。讲解所用的知识从这里获取，而不是凭模型记忆猜测。实践经验来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练的科学与实践》，Zatsiorsky & Kraemer](https://example.com)
  周期化训练与身体适应的基础著作。用于：周期化、恢复、强度区间相关的所有问题。
- [文章：《我该练多少？》，Greg Nuckols](https://example.com)
  训练量指标的循证综述。用于：每个肌群的每周组数目标。

## 经验（社区）

- [某高质量训练论坛](https://example.com)
  信息质量高，严格管理伪科学内容。用于：训练计划点评、平台期排查。
- 线下：{健身房名称} 周二力量课
  用于：动作的现场指导反馈。
```

## 规则

- **只收录高可信来源。** 优先选择一手资料、公认专家、同行评审研究和管理严格的社区。不收录以教育为名的营销内容。
- **每条都加说明。** 只有链接的条目三个月后就没有用处了。加一行说明：讲什么，什么时候查阅。
- **按知识和经验分组。** 与 [SKILL.md](./SKILL.md) 中的教学理念对应。一个资源只出现在其中一组也可以。
- **明确列出缺口。** 学习目标需要的某部分内容没有好资源时，写一节 `## 缺口` 列出来，指导后续搜索。
- **定期删减。** 被证明错误、内容浅显或偏离学习目标的资源直接删除。五个高质量来源胜过三十个普通来源。
- **记录社区偏好。** 用户选择不加入社区时，记录在这里，之后的会话就不再重复推荐。
