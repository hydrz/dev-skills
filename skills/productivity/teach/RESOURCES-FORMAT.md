# RESOURCES.md 格式

`RESOURCES.md` 是这个主题精选的可信来源。讲解所用的知识从这里取，而不是凭参数记忆猜。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练的科学与实践》，Zatsiorsky & Kraemer](https://example.com)
  周期化与适应的奠基之作。用于：周期化、恢复、强度区间相关的一切。
- [文章：《我该练多少？》，Greg Nuckols](https://example.com)
  训练量标志点的循证综述。用于：每个肌群的每周组数目标。

## 智慧（社区）

- [某高质量训练论坛](https://example.com)
  高信噪比，严格管理伪科学。用于：训练计划点评、平台期排查。
- 线下：{健身房名} 周二力量课
  用于：动作的实时指导反馈。
```

## 规则

- **只收高可信。** 优先一手资料、公认专家、同行评审的研究、管理严格的社区。披着教育外衣的营销内容不收。
- **每条都加注释。** 光秃秃的链接三个月后毫无用处。加一行：讲什么、什么时候去翻。
- **按知识 / 智慧分组。** 与 [SKILL.md](./SKILL.md) 的理念对应。一个资源只出现在其中一组也可以。
- **显式列出缺口。** 使命需要的某块没有好资源，就写一节 `## 缺口` 列出来，驱动后续搜索。
- **无情修剪。** 被证明是错的、浅的、偏离使命的资源直接删掉。五个锋利的来源胜过三十个平庸的。
- **记录社区偏好。** 用户选择不加入社区，记在这里，之后的会话就不再反复推荐。
