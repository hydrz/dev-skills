# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范语言。所有讲解、练习、学习记录都遵循其中的术语。构建它本身就是学习的一部分：能把一个概念压缩成紧凑的定义，就是理解的证据。

## 结构

```md
# {主题} 术语表

{一两句话说明这份术语表覆盖的主题。}

## 术语

**肌肥大**：
由机械张力和代谢压力在多次训练中驱动的肌肉增长。
_避免_：增肌、练大

**渐进超负荷**：
通过负重、容量或强度，系统性地随时间增加对肌肉的要求。
_避免_：加把劲、升级

**RPE（自觉用力程度）**：
对一组动作有多吃力的 1 到 10 分自评，10 表示力竭，8 表示还能再做两次。
_避免_：用力分、强度评分
```

## 规则

- **用户理解了才收词。** 术语表记录的是已压缩的知识，不是让用户去学的词典。用户刚接触某个概念，等到他们能正确使用时再收进来。
- **立场鲜明。** 同一概念有多个说法时，选最好的一个，其余列为 _避免_ 的别名。语言就是这样被压缩的。
- **定义要紧。** 一两句。定义它*是*什么，不写它做什么或怎么做。
- **定义里也用术语表的词。** 一个词进了术语表，就处处优先使用它，包括其他词条的定义里。这样复杂概念以后更容易掌握。
- **自然成簇时加小标题分组**（如 `## 解剖`、`## 训练编排`）。词条内聚时平铺即可。
- **显式标出歧义。** 某词在领域里用得很松散，写明本工作区的约定："本工作区里'组'一律指正式组，热身组单独记录。"
- **理解加深就修订。** 第一周写下的定义到第六周可能是错的。就地更新，保持每个词条都是当前的理解。
