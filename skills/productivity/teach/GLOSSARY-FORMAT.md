# GLOSSARY.md 格式

`GLOSSARY.md` 是这个学习工作区的标准用语。所有讲解、练习和学习记录都遵循其中的术语。建立术语表本身就是学习的一部分：能把一个概念概括成简洁的定义，说明已经理解了它。

## 结构

```md
# {主题} 术语表

{一两句话说明这份术语表覆盖的主题。}

## 术语

**肌肥大**：
由机械张力和代谢压力在多次训练中驱动的肌肉增长。
_避免_：增肌、练大

**渐进超负荷**：
通过负重、训练量或强度，随时间系统性地增加对肌肉的要求。
_避免_：加把劲、升级

**RPE（自觉用力程度）**：
对一组动作吃力程度的 1 到 10 分自评，10 表示力竭，8 表示还能再做两次。
_避免_：用力分、强度评分
```

## 规则

- **用户理解后才收录。** 术语表记录的是已经掌握的知识，不是让用户去背的词典。用户刚接触某个概念时，等到用户能正确使用它，再收录进来。
- **明确选定用词。** 同一概念有多种说法时，选择最合适的一个，其余列为 _避免_ 的别名。统一用词能让表达更简洁。
- **定义要简洁。** 一两句话。定义它*是*什么，不写它做什么或怎么做。
- **定义中也使用术语表的词。** 一个词进入术语表后，所有地方都优先使用它，包括其他词条的定义。这样以后更容易掌握复杂概念。
- **术语自然成组时，用小标题分组**（例如 `## 解剖`、`## 训练安排`）。词条内容紧密相关时，直接平铺即可。
- **明确标出歧义。** 某个词在领域中用法很宽泛时，写明本工作区的约定，例如：“本工作区中的‘组’一律指正式组，热身组单独记录。”
- **理解加深时及时修订。** 第一周写下的定义到第六周可能已经不准确。就地更新，让每个词条都反映当前的理解。
