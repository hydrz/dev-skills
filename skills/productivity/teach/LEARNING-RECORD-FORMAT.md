# 学习记录格式

学习记录放在 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md`。目录在写第一条记录时再创建。

它们是教学版的 ADR：记录非显而易见的收获、关键洞见，以及用户声明的已有知识，这些会引导之后的会话。用来推算最近发展区。

## 模板

```md
# {学到了什么 / 确认了什么的简短标题}

{1 到 3 句：学到了什么（或确认了哪些已有知识），以及它为何影响之后的会话。}
```

这就是全部格式。一条学习记录可以只有一段。价值在于记下*这件事现在已经掌握*以及*它为什么改变接下来教什么*，而不在于填满各个小节。

## 可选小节

只在确有价值时加。大多数记录用不到。

- **状态** frontmatter（`active | superseded by LR-NNNN`）：早先的理解被证明有误并被取代时有用。
- **证据**：用户如何展示了理解（答对了问题、完成了练习、引用了过往经验）。论断可能被重新审视时有用。
- **影响**：这解锁了或排除了之后的什么。非显而易见时值得写。

## 编号

扫描 `./learning-records/` 找到最大编号，加一。

## 何时写学习记录

满足任一条就写：

1. **用户展示了对非平凡内容的真正理解**：不只是接触过，而是有证据表明能正确运用。这抬高了接下来教学的起点。
2. **用户说明了已有知识**："我已经会 X 了。"记下来，之后的会话就不重复教。同时记下他们声称掌握的*深度*。
3. **纠正了一个误解**：用户之前相信某个错误说法，现在明白了为什么错。这类价值很高，能预测相关主题上会绊倒的地方。
4. **学习让使命发生了转移**：用户发现自己真正在意的和原先想的不一样。交叉链接 [[MISSION.md]] 并更新它。

### 不算数的

- 只是讲过的内容。讲过不等于学会，等证据。
- 已在 [[GLOSSARY.md]] 里以术语定义简洁记录过的内容。
- 逐次会话的活动日志。学习记录是可供决策的洞见，不是日记。

## 取代

后一条记录与前一条矛盾时（用户理解加深或被纠正），把旧记录标为 `Status: superseded by LR-NNNN`，保留而不删除。理解如何演进的历史本身就是有用的信号。
