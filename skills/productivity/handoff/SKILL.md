argument-hint: "下一个会话要用来做什么？"

写一份交接（handoff）文档，概括当前对话，让一个全新的 agent 能接着干。保存到用户操作系统的临时目录，不放进当前工作区。

文档包含：

- **目标**：这件事最终要到哪里。
- **当前状态**：已完成什么、进行到哪一步、哪些是确定的、哪些还悬而未决。
- **关键决策与理由**：只写产物里没记录的"为什么"。
- **下一步**：新会话第一件该做的事。
- **建议使用的 skill**：列出下一个 agent 应该调用 Skill 工具去用的 skill。

已经记录在其他产物里的内容（规格、计划、ADR、issue、提交、diff、台账），用路径或 URL 引用，不重复抄写。

脱敏：API key、密码、个人身份信息一律替换成 `<已脱敏>`。

用户传了参数的，把它当作下一个会话的重点，据此裁剪文档。

写完后告诉用户文件的绝对路径。
